**Your guards: what you can use** (this guide appears with the first message of every session until {until})

Words, typed as a whole message:
- `guards off` / `guards on`: everything off / on
- `free` / `focus`: allow wandering / end it; `free` also lifts the session block
- `carry`: you are tired, Claude takes the small decisions
- `landing` (or `done for today`): start landing mode; `continue anyway` ends it
- `brief off` / `brief on`: start brief off for today / on again
- `reeval`: did the guards help?

What is active for you and why: `ACTIVE.md` and `PROFILE.md` in the guards folder.
